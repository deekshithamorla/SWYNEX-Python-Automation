# SWYNEX Python Automation Tool

## Task 2

This project is a simple Python automation tool that categorizes files based on their file type.

## Features

- Identifies different file types
- Categorizes images, documents, audio, and videos
- Uses Python conditional statements and file extension checking
- Reduces manual file categorization work

## File Categories

- JPG and PNG → Images
- PDF and TXT → Documents
- MP3 → Audio
- MP4 → Videos

## Technologies Used

- Python
- Online Python Compiler
- GitHub

## How It Works

The program checks the extension of each file and automatically assigns it to the appropriate category.

## Result

The program successfully categorizes sample files into Images, Documents, Audio, and Videos.
